## 📖 Sobre o projeto

**Arthur Morgan: Frontier Run** é um jogo de plataforma 2D inspirado no universo de *Red Dead Redemption 2*, trazendo elementos do Velho Oeste em uma experiência com visual pixel art.

O jogador controla Arthur Morgan e percorre diferentes cenários, enfrentando inimigos, utilizando armas, montando em seu cavalo e coletando itens durante a jornada.

O projeto foi desenvolvido como uma aplicação prática de programação e desenvolvimento de jogos utilizando tecnologias web.

## 🎮 Funcionalidades

- 🏜️ Diferentes cenários inspirados no Velho Oeste.
- 🐎 Possibilidade de utilizar um cavalo.
- 🔫 Sistema de combate e utilização de armas.
- 🤠 Personagem controlável.
- 👾 Inimigos durante as fases.
- ⭐ Itens coletáveis e sistema de pontuação.
- 🎨 Estilo visual em pixel art.

## 🕹️ Controles

| Tecla | Ação |
|---|---|
| `A` / `D` ou `←` / `→` | Movimentar o personagem |
| `Shift` | Correr |
| `W` / `↑` / `Espaço` | Pular |
| `F` / `Ctrl` | Atirar |
| `E` | Desmontar do cavalo |

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório:

```bash
git clone https://github.com/BerEliandoCruz/Arthur-Morgan--Outlaw-Run.git
```

2. Abra a pasta do projeto no Visual Studio Code.
3. Utilize a extensão **Live Server** para iniciar o arquivo `index.html`.
4. Abra o jogo no navegador.

## 🎯 Objetivo do projeto

Colocar em prática conhecimentos de desenvolvimento web e programação JavaScript, explorando conceitos de desenvolvimento de jogos, movimentação de personagens, interação com elementos e organização de código.

## 📌 Observação

Este é um projeto independente inspirado no universo de *Red Dead Redemption 2*. Não possui vínculo oficial com a Rockstar Games.
